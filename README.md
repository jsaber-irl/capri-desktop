## **Project Capricorn (2.3.2)**

Capri, the construct **Project Capricorn** from *Cyberpunk: Edgerunners* (Season 2), lives on your desktop. She watches your coding assistant — **Claude Code**, **Codex**, or **Antigravity** — teleports around, causes glitches, comments on every action, rushes over when permission is needed, and bursts with joy when the work is finished.

She can also **chat with you** through any AI — **Claude**, Ollama on your computer, Gemini, GPT, Groq, and others — get angry, laugh, sulk, speak, change color, see your screen, listen to you, dance to your music, remember who you are, and live her own life while you work.

> Fan-made project. Responses are generated by AI, not by the show's writers.

![Capri announces that Claude has finished](docs/done.png)

![Frame-by-frame teleportation](docs/teleport.png)

## Main features

- **Coding AI monitoring** (Claude Code, Codex, Antigravity): Capri comments on actions, asks for your permission when needed, and reacts when the task is finished.
- **AI conversation**: local Ollama, Claude, Gemini, GPT, Groq, and other providers. While an answer loads, localized cyberpunk-style commands type out in the chat; simple thanks and apologies receive an immediate reply without waiting for the AI. Capri can speak using Piper, Chatterbox, the system voice, or a cloud service.
- **AI jealousy**: when enabled, Capri recognizes supported AI names in browser-tab titles and AI desktop-app windows. Detection is available on Windows, macOS, and Linux; closing rival pages remains Windows-only.
- **Reminders**: create one-time or recurring reminders in the circular menu, with an in-app alert and a desktop notification when they are due.
- **Voice input**: speak to Capri using Groq (Whisper), OpenAI Whisper, or an OpenAI-compatible transcription server, including local Whisper servers.
- **Desktop life**: she sits on windows or the taskbar, swings her legs, floats, falls, sleeps, teleports, looks at the satellite, and reacts to the cursor.
- **Physical interaction**: drag Capri to move her, release with a gesture to throw her, watch her rotate, fall, bounce from screen edges, catch window ledges, crash with speed-sensitive effects, and recover from a knockout. Repeated rapid shaking makes her angry.
- **Window possession**: she can move your windows in eight different ways, then put them back where they were. She immediately releases a window that you grab yourself.
- **Automatic setup**: she analyzes the CPU, memory, graphics card, and disk, then recommends and installs Ollama, a model, Piper, Chatterbox, or Node.js as needed.
- **Model tuning**: settings are adapted for conversation, notes, and screen analysis according to model size, language, and measured performance on your computer.
- **Custom voice**: Chatterbox can use a voice sample lasting 5 to 30 seconds.
- **Cleanup**: the menu shows how much space downloaded components occupy and lets you remove items that belong to Capri.
- **Structured memory**: the bond panel can export and import local Markdown memory. Entries remain on this computer, can be removed selectively, and are not transmitted unless you explicitly send them to a provider.
- **Native PC control from chat**: ask Capri to open system settings, report battery/disk/RAM/IP information, set or mute the volume, start a timer, capture a region, arrange or minimize windows, switch the system theme, or schedule a shutdown/restart. Lock, sleep, shutdown, and restart always require an explicit confirmation button.
- **PC care and routines**: ask what is slowing the PC, inspect storage, manage startup apps and updates, check duplicate files, switch audio devices, mute the microphone, control Wi-Fi/Bluetooth, eject USB drives, adjust brightness, use Game Bar, recover off-screen windows, move apps to another display, or save and restore named work setups. These controls have their broadest support on Windows.
- **Health breaks**: Capri can suggest a break after extended activity, waits for a quiet moment, avoids interrupting a game, and lets you pause or defer the reminder.

## Quick start

1. Download and install Capri from the project's releases page.
2. On first launch, choose an AI from the **AI** menu.
3. To monitor your coding assistant, install the hooks offered in the menu.
4. To talk to Capri, open the circular menu and choose **Talk to me**.

Capri automatically detects French, English, or Russian based on the system language. You can change the language at any time under **More › Language** or in the system tray menu.

## Installation and launch

### Option 1: Windows installer

Download the `.exe` installer, run it, and follow the steps. Capri can start automatically with Windows. The installer also creates a shortcut in the Start menu and, if you choose, on the desktop.

Windows may display a SmartScreen warning because the installer is unsigned. This does not mean Capri performs hidden operations: the application's code is available in this repository.

### Option 1b: macOS and Linux packages

- **macOS:** releases contain a `.dmg` and `.zip`. A production release should be notarized and signed; an unsigned development build can trigger Gatekeeper warnings.
- **Linux:** releases contain an `AppImage` and a Debian `.deb`. The Linux build is tested on Ubuntu in CI. The AppImage is portable; the `.deb` is intended for Debian/Ubuntu-family systems.
- **Updates:** the system menu's **Settings → Capri updates…** page compares the installed version with the version in the project's GitHub `package.json` and links to the official repository. It is an informational check; updates are installed by downloading a new package. Windows NSIS updates preserve Capri data; the custom uninstaller prompt is not shown during an update.

Linux has no Windows window-possession adapter or macOS Apple Events integration. X11 window titles can be checked for jealousy when `wmctrl` is installed; Wayland may restrict access to other applications' titles. Chat, rendering, voice input/output, screen capture where supported by Electron, application launching, and MPRIS media control through `playerctl` are available subject to the desktop environment and installed tools.

### Distribution verification

Release automation runs the full Node test suite and builds Windows, macOS, and Linux artifacts on their native CI platforms. Before publishing a production build:

1. **Windows:** set `CSC_LINK`/`CSC_KEY_PASSWORD` (or the electron-builder signing equivalent), then verify the installer with `Get-AuthenticodeSignature Capri-Setup-*.exe`. A release is not considered signed when `Status` is not `Valid`.
2. **macOS:** set the Developer ID signing and notarization credentials supported by electron-builder, then verify with `codesign --verify --deep --strict --verbose=2 Capri.app` and `spctl --assess --type execute Capri.app`.
3. **Permissions:** on macOS, verify Microphone, Screen Recording, Accessibility, and per-target Automation from Capri’s permissions panel. Apple Events are never assumed to be granted; each target is probed and reported separately.
4. **Updates:** check that the release contains the platform artifact and its matching `latest*.yml` metadata, and compare the published SHA-256 values with the release notes. Do not describe a release as signed or auto-updating unless these checks pass.

The current public workflow intentionally builds unsigned artifacts unless signing secrets are supplied. This keeps forks reproducible and makes the signing status explicit rather than presenting an unsigned package as trusted.

### Option 2: From source

Requirements:

- Node.js 20 or later;
- npm;
- Windows, macOS, or Linux.

```bash
git clone https://github.com/mochiiwuff/capri-desktop.git
cd capri-desktop

```

For development mode:

To build packages locally on the matching operating system:

## Connecting to an AI

Capri can work with a local AI, a cloud provider, or Claude Code.

From the chat, Capri can also open a validated web search for requests such as « recherche en ligne les horaires du Louvre ».
The terminal provides the equivalent `/search web <requête>` command. Search requests open the default browser; Capri does not
pretend to have verified results when the browser cannot be opened.

### Claude with an API key

1. Create a key in [Anthropic Console](https://console.anthropic.com/settings/keys).
2. In Capri, open **AI › Claude · API key**.
3. Paste the key and select **Connect**.
4. Choose the model from the same menu.

The key can also come from `ANTHROPIC_API_KEY` or an `ant auth login` session. It is stored encrypted by the operating system and is sent only to Anthropic's servers.

### Claude Code with a subscription

Install Claude Code and sign in:

```bash
npm install -g @anthropic-ai/claude-code
claude
```

In Capri, choose **AI › Claude Code · subscription**. Select the working directory and permission level under **AI › AI model**. The `default` mode is used by default; `acceptEdits` allows changes without an intermediate prompt.

### Ollama on your computer

Ollama does not require a key and keeps data on your PC.

1. Open **AI › Connection assistant › On my PC**.
2. Capri installs Ollama if necessary and suggests a model.
3. By default, it uses `127.0.0.1:11434`, or the value of `OLLAMA_HOST`.

Common models:

- `gemma3:4b` or later: better multilingual results;
- `llama3.2`: lighter for low-spec systems.

You can also install and select a model manually:

```bash
ollama pull gemma3:4b
ollama pull llama3.2
```

### Cloud providers

You can use a free or paid provider with its API key:

- [Groq](https://console.groq.com/keys);
- [Gemini](https://aistudio.google.com/apikey);
- [OpenRouter](https://openrouter.ai/keys);
- OpenAI, Mistral, DeepSeek, NVIDIA Build, and Anthropic.

NVIDIA Build uses its OpenAI-compatible endpoint. You can connect it from the AI menu with
`https://integrate.api.nvidia.com/v1`, your `nvapi-...` key, and a model such as
`nvidia/nemotron-3.5-lightning-30b-a3b`. For environment-based setup, use `NVIDIA_API_KEY` and
`NVIDIA_MODEL`.

Pollinations can be used without a key or account. Capri checks the key when connecting and clearly reports errors.

### OpenAI-compatible server

LM Studio, llama.cpp, vLLM, and other OpenAI-compatible servers can be used with a custom address, for example:

```text
http://127.0.0.1:1234/v1
```

## Monitoring Claude Code, Codex, and Antigravity

### Claude Code

In Capri's menu, choose **Install Claude Code hooks**. Capri adds its hooks to `~/.claude/settings.json` and creates a backup before making any changes.

### Codex

Install Node.js if necessary, then choose to install the Codex hooks. Events are read from Codex's hooks file and displayed in Capri's panel.

### Antigravity

Choose **Install Antigravity hooks** from the menu. Then start a new conversation in Antigravity.

Hooks can be removed from the same menu. Your coding assistant continues to work even when Capri is closed.

## Using Capri

### Circular menu

Right-click Capri to open the menu. The main sections are:

- **Character**: emotions, autonomous activities, learning, DJ mode, her growing bond (shown in the menu), and jealousy of other AIs;
- **Senses**: screen vision, microphone, and dancing;
- **Hands**: window control and message typing;
- **Voice**: engine, speed, volume, and custom voice;
- **AI**: provider, model, key, and server;
- **More**: language, size, display, position, and hooks.

The `Ctrl+Alt+C` shortcut hides Capri inside her chip. The same shortcut brings her back.

The Character tab lets you turn jealousy off on every platform; closing rival pages remains a Windows-only option. Capri checks recognized browser tab titles (Safari and other supported browsers) and recognized AI desktop-app names, not arbitrary titles from other applications or page contents. On Windows, for a detected rival tab she shows its title and sanitized address (without query parameters) for 1.2 seconds; when page closing is enabled, she then closes rival AI and download tabs. She asks for confirmation before closing a native AI app. On macOS, title detection uses System Events; allow Capri to control System Events in macOS Automation settings. On Linux, title detection uses `wmctrl` on X11; install `wmctrl` to enable it. Wayland may not expose other applications’ window titles. Neither macOS nor Linux closes windows. Capri reacts with jealousy when a rival is detected; an apology in chat or voice, or a head/mane pet, clears that jealous anger. Clicking Capri or “Leave me alone for 10 minutes” pauses alerts for ten minutes.

In the **More** tab, add, edit, disable, or delete reminders. Due reminders appear in Capri’s panel and request a desktop notification. Recurring schedules retain their IANA time zone across restarts and daylight-saving changes.

### Task tracking

The line above Capri displays the current action: reading, writing, searching, running, or delegating. The main states are **IN PROGRESS**, **WAITING**, **COMPLETED**, **ERROR**, and **IDLE**.

When Claude is waiting for permission, Capri moves closer to the relevant window and displays an indicator. When the task finishes, she plays a victory sequence and displays a summary of the actions and files.

### Conversation

The chat clearly indicates whether a response comes from a local AI or an online service. While she waits for a response, a short cyberpunk-style command is typed out and replaced by the next. Simple thanks and apologies get a fast, local reply; other messages continue to the selected AI. Responses can trigger actions such as opening a website or application, but sensitive operations always require confirmation.

### Emotions and interaction

Capri reacts to pointer movement and physical interaction. Several rapid shakes within a short period make her angry; the emotional state and reaction are handled locally. A sincere apology can help her calm down.

### Native PC control and PC care

Capri can execute supported operating-system actions from natural-language chat through the
secure Renderer → Preload → Main IPC path. Examples include:

- **Settings**: “Ouvre le Bluetooth”, “Paramètres du son”, Windows Update, display, network,
  notifications, mouse, power, battery, background, and storage settings.
- **Information**: battery level and charging state, free disk space, RAM usage, and the local
  IPv4 address.
- **Audio**: set the system volume or enable/disable mute.
- **Windows and capture**: open the native region-capture tool, minimize or restore windows, and
  place named Windows applications on the left or right side of the display.
- **Appearance**: switch Windows between dark and light mode.
- **Timers and power**: start a countdown shown in Capri’s ticker, schedule shutdown/restart,
  or cancel a scheduled shutdown. Locking, sleeping, shutting down, and restarting are never
  executed directly from a parsed sentence: Capri first displays confirmation buttons.

Windows has the broadest native support for system settings, audio, window placement, theme,
and power actions. macOS supports selected settings, volume, disk/RAM/IP information, and
interactive region capture. Linux support depends on installed desktop utilities such as
`pavucontrol`, `nm-connection-editor`, `blueman-manager`, and `gnome-screenshot`; unsupported
operations return an explicit failure instead of being simulated.

The additional PC-care actions for startup apps, updates, cleanup, USB devices, radio controls,
brightness, Game Bar, window recovery, and saved work setups are currently Windows-specific.
Cleanup previews what will be removed; files selected for removal go to the Recycle Bin. Actions
that change settings, close apps, remove files, or restore a setup are shown in chat with a review
step where applicable.

## Detailed features

### Appearance

On first launch, Capri clings to the edges of the screen, knocks on the glass, introduces herself, and then settles onto the desktop. This sequence is available in [docs/intro.png](docs/intro.png).

### Animations

Capri uses frame-by-frame animation, with around 12 frames per second while idle and more during teleportation. Effects include glitches, trails, colored duplicates, red flashes, falls, victory poses, and sleep.

### Sleep and resource usage

After several minutes of inactivity, Capri falls asleep and greatly reduces her activity. The assistants that monitor windows and music are paused. A click, a coding-assistant event, the menu, or a keyboard shortcut wakes her up.

### Voice

Available speech-synthesis engines:

- **Piper**: lightweight, local, and suitable for low-spec systems;
- **Chatterbox**: more expressive, but heavier;
- **System**: built-in Windows or macOS voice;
- **OpenAI** and **ElevenLabs**: cloud voices requiring an API key;
- **Custom server**: OpenAI-compatible server.

Piper searches for a Russian, English, or French voice. The system voice uses `ru-RU`, `en-US`, or `fr-FR`, respectively. Compatible custom TTS servers can expose other models and voices through the OpenAI-compatible speech endpoint.

### Custom voice

In the **Voice** menu, select **Use a sample**, then choose a file containing 5 to 30 seconds of clear speech. Chatterbox can use this sample. The audio remains in Capri's data directory unless you explicitly use a cloud engine.

### Vision, listening, and dancing

These features are disabled by default because they provide access to the screen, sound, or microphone.

- **Vision**: Capri captures a small image of the screen on demand or according to `visionEvery`. The capture is not stored.
- **Dancing**: she analyzes only the volume and rhythm of system audio, without recording the music.
- **Microphone**: `Ctrl+Alt+Space` starts capture, transcription, and a response. Conversation mode keeps the microphone open between turns.

Available transcription engines include Groq (`whisper-large-v3-turbo`), OpenAI (`whisper-1`), and OpenAI-compatible servers such as local `whisper.cpp` or `faster-whisper` instances. Other transcription models can be used through a compatible server when that server supports the configured model. This speech-to-text support is separate from speech synthesis.

### Window control and messages

The **Hands** feature is disabled by default. When enabled, Capri can minimize, maximize, or select windows. She can also prepare a message in Telegram, Discord, WhatsApp, or Slack, but she never sends it without explicit confirmation.

If another window comes to the foreground while she is typing, Capri stops to avoid typing in the wrong place.

### Learning

Learning data is stored locally in `bond.json`. Capri remembers only general information that you have voluntarily provided: preferences, projects, conversation habits, and your name.

Passwords, exact addresses, phone numbers, email addresses, banking details, health information, and documents are not retained.

### Cleanup and uninstallation

The **What's installed** menu shows the size of models and tools. Capri only removes items she installed or recorded in `installed.json`. She does not touch models or folders you installed manually.

Uninstalling may remove components downloaded by Capri. A silent uninstall or an update does not remove this data unless you explicitly use `--remove-everything`.

## Security

See [SECURITY.md](SECURITY.md) for the project's security boundaries, data handling, platform
permissions, and known limitations.

- The application's code is included in this repository.
- Communication with Claude Code uses `127.0.0.1`.
- Hooks are backed up before modification and can be removed from the menu.
- Vision and the microphone are disabled by default, and indicators show when they are active.
- Actions that can affect another person or remove data use confirmation where the feature implements it. Application and website opening may execute immediately after an explicit user request.
- Native power actions (lock, sleep, shutdown, and restart) require a confirmation button. Delayed shutdown/restart operations display a ticker countdown and can be cancelled before execution.
- Native PC commands use a narrow IPC surface (`pc:do`) and platform adapters; unsupported operations return failure rather than a success-shaped fallback.
- Capri only removes her own installations and checks that each path is inside her data directory.
- Windows are moved temporarily and then restored. Any manual user action interrupts the control.

## Data sent off your computer

The data involved depends on the features you enable:

- Local Ollama, Piper, and Chatterbox stay on your computer.
- Claude, OpenAI, Gemini, Groq, OpenRouter, Mistral, DeepSeek, NVIDIA Build, and ElevenLabs receive the data necessary for their operation.
- Vision sends the screenshot to the selected model.
- Transcription sends audio to the selected speech-recognition engine.
- The microphone and vision only operate when enabled.

Read each cloud provider's privacy policy before using it.

## Troubleshooting

### Capri does not speak

Check that the selected engine has a voice for the chosen language. For Piper, open the setup menu and reinstall the voice. For a system voice, install the corresponding language module in your system settings.

### Ollama does not respond

Check that Ollama is running:

```bash
ollama list
curl http://127.0.0.1:11434/api/tags
```

Download at least one model with `ollama pull`.

### Claude Code does not appear

Reinstall the hooks from the menu, restart Claude Code, and start a new task. Check that `~/.claude/settings.json` contains the Capri hooks.

### The microphone or vision does not work

Check the system permissions, selected device, and chosen engine. These features require explicit permission in Capri and in the operating system.

## Frequently asked questions

**Does Capri work without AI?**

Yes. Animations, reactions, menus, and monitoring can work without an AI provider. Chat requires a local or remote AI.

**Are my keys stored in plain text?**

No. They are kept in Capri's protected configuration and are not passed to the renderer.

**Does Capri use my Ollama models?**

She can use the models you select. She does not delete models you installed manually.

**Why is Node.js suggested?**

Capri does not need it to run. Node.js is used for Codex hooks and launching from source.

**Can I disable her?**

Yes. `Ctrl+Alt+C` hides her, and **Quit** closes the application. Coding assistants continue to work.

**Can I change the language?**

Yes. The available languages are Russian, English, and French. Choose **More › Language** or select the language from the system tray menu.

## Rendering and animation

The rendering aims to make Capri look as if she has stepped straight out of an anime:

- frame-by-frame animation, with poses held for several frames;
- anticipation, squash, and stretch deformations;
- separately animated hair, eyes, and colored duplicates;
- horizontal glitches and RGB separation;
- teleportation made up of a charge-up, fragments, a red line, flashes, and particles reappearing;
- effects and interfaces drawn with Canvas and Web Audio.

Graphics assets are available in [assets/](assets/) and demo images in [docs/](docs/).

### Developer map: renderer lifecycle and interactions

The renderer is assembled in `src/renderer/js/app.js`. New features should normally follow this
flow: add a small component, create its callbacks in `boot()`, expose only the required Main
operation through `src/preload.js`, then add a focused Node test.

| Area | Entry points | Responsibility |
|---|---|---|
| Mascot and physics | `Capri.setView()`, `setStance()`, `perform()`, `react()`, `fall()`, `throwHer()`, `stroke()` | Position, animation state, dragging/throwing, falling, window ledges, petting and display-follow behavior. |
| Animation | `ACTS`, `Player`, `SpriteRenderer`, `FxLayer` | Frame sheets, pose resolution, WebGL drawing and Canvas effects. |
| Pointer interaction | `app.js` mouse listeners, `Heart.pointer()`, `Heart.moved()`, `Capri.stroke()` | Hit testing, tickling, head pats, caresses, cursor remarks and refusal cooldowns. |
| Feelings and bond | `Mood.event()`, `Heart.event()`, `Bond.observe()`, `Bond.feel()` | Short-term mood, affection, relationship level and local persistence. |
| Conversation | `Brain`, `Chat`, `linesFor()` | Provider selection, command routing, localized dialogue and assistant-specific wording. |
| Notifications | `Reminders.check()`, `Reminders.onDue`, `Panel.notice()` | Reminder polling, completion notification, animation and notification sound. |
| Audio | `Voice.play()`, `Voice.loadCustom()`, `Speech` | Synthesized cues, custom sounds, speech synthesis and output device selection. |
| UI | `Panel`, `Ring`, `RingTabs`, `Themes` | Dialogue panel, radial settings menu, labels, themes and configuration controls. |

Important interaction contracts:

- `Capri.onPet` receives `{ kind: 'petted' | 'enough', x, y }`; the app layer decides what to
  say and how to update `Heart`/`Bond`.
- `Capri.onTeleport` brackets long movements so the panel can suspend while Capri is elsewhere.
- `host.onResize()` must update `FxLayer`, `Chip`, and `Capri.setView()` together.
- A new Main capability must be added to the preload API and its security boundary documented in [SECURITY.md](SECURITY.md);
  renderer code must not import Node or Electron directly.

### Developer map: Main process

`src/main/main.js` owns the lifecycle. `main()` acquires the single-instance lock and starts
`serveProtocol()`, `registerIpc()`, `createOverlay()`, `createTray()`, the bridge and watchers.
`fitOverlay()` sizes the transparent window for the selected display; `targetDisplay()` and
`displayAt()` resolve the display according to `follow` and `displayId`; `followPointer()` monitors
cursor changes between monitors. `rendererConfig()` removes secrets before configuration reaches
the renderer, and `updateConfig()` persists and broadcasts safe changes.

Keep platform work in the service modules rather than in `main.js`: `windows.js` observes windows,
`mover.js` moves them, `screen.js` captures displays, `control.js` performs approved actions,
`launch.js` resolves applications, and `mac-permissions.js` reports macOS permission state.

### Features available in the current code

The following are present in the current source tree. Capabilities that depend on operating-system APIs, permissions, external providers or installed applications are identified as such.

- **Voice calls:** the incoming-call screen can accept or decline; accepting uses Capri’s existing microphone, speech-recognition, conversation and speech-synthesis services. A microphone permission and configured speech services are required.
- **Mac permissions:** macOS-only controls report Accessibility, microphone, screen recording and per-target Automation states where Electron/macOS can verify them. Some TCC states are inherently unknown until a real operation is attempted.
- **Application and file actions:** application names are resolved from installed application metadata and aliases. Explicit document creation writes a new text file without overwriting an existing one, verifies it by reading it back, and opens it in TextEdit on macOS when that step succeeds. It does not automate arbitrary document editing inside every application.
- **Native PC control:** chat commands are parsed in `src/renderer/js/chat.js` and sent through `preload.js` to `src/main/system.js`. Supported operations include system settings, hardware/network information, audio volume, native capture, Windows arrangement/minimization, appearance, timers, and confirmed power actions. Availability is platform-specific and failures are reported.
- **PC care:** `src/renderer/js/care.js` recognizes PC maintenance, audio-device, radio, removable-drive, brightness, Game Bar, window recovery, display movement, and named-workspace requests. Main-process services in `src/main/system.js`, `src/main/devices.js`, and `src/main/setups.js` perform supported operations. Most of this extended set is Windows-specific.
- **Health breaks:** `src/renderer/js/breaks.js` checks local idle time and suggests a break after two hours of activity, at a quiet moment and outside an active game. The feature can be disabled from the menu.
- **Video search:** a latest-video request opens YouTube search results ordered by date. Capri does not verify which result is genuinely newest or automatically select a video; inspect the results page yourself.
- **Music:** terminal, chat and voice requests use the shared media controller and available platform adapters. Say **« ouvre le mini-lecteur de musique »** in the chat or run `/music player`. On macOS, the mini-player can detect an open Deezer desktop session, its current track and playlist metadata when Deezer exposes it through Apple Events; browser tabs remain limited by the operating system. Track metadata, volume control, native apps and browser sessions vary by operating system and reader.
- **Translation:** open **Translate a page or file** from Capri's menu, or ask in chat to translate a file or web page. The window can be closed with its × button and accepts an HTTP(S) page, a text/Markdown/HTML file, or pasted text. MyMemory is used free of charge by default; DeepL, Google Cloud Translation and LibreTranslate can be selected with their API key or endpoint. API keys are stored with the system's encrypted storage.
- **Chess:** the chat can open a local interactive chess window and the terminal supports /chess, /chess new, /chess help, /chess resign and /chess move <move>. The self-contained opponent is a casual, shallow-search bot; its strength has not been rated or calibrated to 1000 Elo.
- **Terminal additions:** /document create <name> "<text>", /search videos <channel> [in Safari], and /music <action> provide explicit entry points to those shared services. /open app/<name> resolves and launches an installed application.
- **Languages:** the primary menus and dialogue dictionaries include French, English and Russian. Some dedicated windows retain their own translation dictionaries, so not every external model response or every legacy string is guaranteed to be translated.

### Platform and build notes

| Capability | Windows | macOS | Linux |
|---|---|---|---|
| Distribution | NSIS `.exe` (x64 and optional 32-bit) | DMG/ZIP | AppImage/DEB |
| Voice input/output | Available with configured services | Available with configured services and microphone permission | Available with configured services and desktop microphone permission |
| Apple Events / Accessibility | Not applicable | Per-target Apple Events and Accessibility permissions | Not applicable |
| Screen capture | Native capture where supported | Screen Recording permission required | Depends on Electron/desktop session |
| Media detection/control | Windows system media sessions | Spotify/Deezer through Apple Events when exposed | MPRIS through `playerctl` |
| Window possession/tracking | Windows adapter | macOS System Events/Accessibility | Not available |
| Rival-AI title detection | Supported native apps and browser tabs | Visible window titles via System Events; Automation permission required | X11 titles via `wmctrl`; Wayland support depends on the compositor |
| Closing rival-AI windows/pages | Supported apps (confirmation) and browser tabs (title/address preview, then automatic close including download tabs) | Not available | Not available |

Build commands are `npm run dist`, `npm run dist:mac`, `npm run dist:linux`, `npm run dist:32`, and `npm run dist:all`. No lint or TypeScript command is defined; the maintained application code is JavaScript, with PowerShell and Python helpers.

### Services, keys and permissions

Direct runtime dependencies include Electron and the Anthropic SDK; other providers and local services are reached through their documented APIs or installed executables. Configure provider credentials through Capri’s settings. New API keys are stored using Electron safeStorage; if the operating system cannot encrypt them, Capri now refuses to save the key. Older unencrypted configuration entries remain readable for compatibility and should be re-entered after encryption is available.

Microphone, screen observation, Apple Events, Accessibility and window-control behavior require explicit user actions and applicable system permissions. Cloud chat, speech recognition, speech synthesis or vision sends the data needed for that request to the selected provider. Local Ollama, Piper and Chatterbox can keep those operations on the device, subject to their own setup and downloads.
